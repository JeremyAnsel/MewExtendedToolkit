    Class TransformBox

    Decorator that applies a composed Matrix3x2 transform before rendering the child. Transform order: Translate(-origin) → Scale → Rotate → Translate(+origin + offset). Origin is relative (0.0–1.0) to the content bounds; defaults to center (0.5, 0.5).
